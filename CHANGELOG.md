# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-06-25

### Added
- Initial release
- `generateQRDxf()` — generate DXF string from QR code content
- `generateQRDxfFile()` — write DXF file directly to disk
- Support for `SOLID` (3DFACE), `HATCH`, and `LWPOLYLINE` entity types
- Configurable cell size, error correction level, margin, and DXF layer
- TypeScript types included
- CJS and ESM dual output
